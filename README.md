# Thineth Spin & Win — responsive front-end prototype

- Mobile-first premium registration screen and animated spin wheel.
- No admin dashboard is shown on the public page.
- Branding contains “2029”, “THINETH”, and “SPIN & WIN”; it does not mention A/L.
- Registration fields: name, WhatsApp number, consent.

## Important
This is a front-end demo. Form entries are stored in the visitor's browser only (`localStorage`); they do not reach an organiser or central dashboard. Do not use it to collect real student data until a secure backend, protected admin authentication, access policies, and privacy notice are configured. The wheel prizes are demo messages and are not a real prize draw.
